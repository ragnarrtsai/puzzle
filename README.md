# puzzle

一個本機拼圖小遊戲。遊戲本身不附任何素材 —— 你把自己的圖片放進來源資料夾，它就變成拼圖。

用 Rust + [macroquad](https://macroquad.rs) 寫的。

## 執行

```bash
cargo run
```

預設讀工作目錄下的 `images/`。想玩別的資料夾：

```bash
PUZZLE_IMAGES=/path/to/其他資料夾 cargo run
```

## 放圖片

```
images/<圖集>/<高_寬>/圖片檔
```

例如：

```
images/
  貓/
    3_4/            ← 3 列 4 行，共 12 片
      tabby.jpg
      calico.png
    5_6/            ← 同一張圖也可以放這裡，算另一個關卡
      tabby.jpg
```

- `<高_寬>` 用**底線**分隔，**列數在前、行數在後**。`3_4` 是 3 列 4 行 = 12 片。
  注意這跟一般講圖片尺寸的習慣（寬在前，如 1920x1080）是相反的。
- `<圖集>` 那層隨你取名，只是幫你分類檔案，遊戲畫面上不會顯示。
- 難度由資料夾決定，遊戲裡沒有難度選單。同一張圖放在不同的 `<高_寬>` 下就是不同關卡。
- `<高_寬>` 那層寫錯（例如 `images/貓/亂寫/`）就整個不讀，不會提示。
- 支援 jpg / jpeg / png / webp。
- 開遊戲時掃一次資料夾。中途丟新圖進去要重開遊戲才看得到。

## 怎麼玩

**選圖畫面**
依難度分區，難度就是拼片總數。最上面那排列出所有難度，點了可以直接跳。每頁四格，每格是完整原圖加上「幾乘幾」。已完成的圖邊框是琥珀色，點進去是欣賞而不是重玩。

**拼圖畫面**
沒有板子，整個畫面就是一張桌子。

- 拼片一開始隨便散，可以互相重疊、疊成一堆
- 滑鼠移過去，抓得起來的東西會亮邊框；已經扣成一組的會整組亮起來
- 拖著跑，相鄰的兩片靠得夠近就自動扣住，之後**一起移動，而且不能再拆開**
- 拼片**不能旋轉**
- 右上角的「偷看原圖」滑過去會顯示原圖當參考
- 左上角「返回」等於棄權，拼到一半的進度不留

**完成**
所有片併成一組時，圖的周圍會有琥珀色金光閃三次、約五秒，然後轉成欣賞畫面。
欣賞畫面右上角的「重置」會清掉完成紀錄並立刻重拼一次。

## 存檔

只記錄哪些關卡拼完了，不存拼到一半的進度。

存檔是純文字檔，放在來源資料夾旁邊 —— 來源是 `images/` 的話就是 `images.completed`，一行一個關卡。
**完成的瞬間就寫檔**，不用等金光放完，所以閃爍途中關掉視窗也算數。

搬走 `images/` 的時候把 `.completed` 一起帶著，進度就跟著走。反過來說，改了資料夾名稱或檔名，
那筆紀錄就對不上了，會變回沒拼過。

## 開發

```bash
cargo test        # 掃描與存檔的單元測試
cargo clippy
```

因為是圖形程式，另外有兩個除錯用的環境變數：

| 變數 | 作用 |
|---|---|
| `PUZZLE_SHOT=前綴` | 把選圖畫面每一頁截成 PNG 然後結束 |
| `PUZZLE_SELFTEST=1` | 自動開第一關並走完整的扣合流程拼完，配 `PUZZLE_SHOT` 可以檢查完成、存檔、金光、欣賞畫面這條路 |

```bash
PUZZLE_SELFTEST=1 PUZZLE_SHOT=/tmp/shot cargo run
```

### 程式結構

| 檔案 | 負責 |
|---|---|
| `src/scan.rs` | 掃描來源資料夾、解析 `<高_寬>` |
| `src/select.rs` | 選圖畫面：難度分區、翻頁、完成標示 |
| `src/board.rs` | 拼圖本體：散落、拖曳、互吸、群組、金光 |
| `src/view.rs` | 欣賞畫面 |
| `src/assets.rs` | 圖片載入與快取 |
| `src/save.rs` | 完成紀錄 |
| `src/ui.rs` | 配色、字型、按鈕 |

幾個實作上的選擇：

- **拼片不是真的切開。** 整張圖只有一張 texture，每片畫的時候指定自己的來源矩形，
  所以 48 片和 4 片的記憶體用量一樣。
- **因為不能旋轉，互吸的判定只是位置比對** —— 兩片該不該扣起來，就看它們的位置差
  是不是接近格子的位移。允許旋轉的話這裡要多一整層角度比對。
- **因為扣起來不能拆，群組只需要合併、不需要分裂**，所以用 union-find 就夠了。
- 載入時會把圖縮到長邊 2048 以內，玩家丟 6000px 的原圖進來也不會吃掉一堆記憶體。
- 介面文字會找系統的 `Arial Unicode.ttf`（macOS 內建）來顯示中文，找不到就自動改用英文。
